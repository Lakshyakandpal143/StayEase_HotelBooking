# StayEase – Full Stack Property Listing Platform

StayEase is a full-stack web application that allows users to explore, create, and manage property listings. The platform provides features such as user authentication, property listings, reviews, image uploads, and interactive maps.

## 🚀 Features

- User authentication and authorization
- Create, edit, and delete property listings
- Browse and view property details
- Upload property images
- Add and manage reviews
- Interactive maps for property locations
- RESTful API architecture
- MVC-based application structure
- Responsive user interface
- Form validation and error handling
